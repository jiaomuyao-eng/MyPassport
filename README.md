# MyPassport
Minecraft Fabric 1.21.1 Passport Mod

## ✨ 模组介绍
一款适用于 Minecraft 1.21.1 Fabric 的通行证模组，可以在游戏内制作、查看通行证。

## 📌 依赖要求
- Minecraft 版本：1.21.1
- Fabric Loader
- Fabric API

## 📦 安装教程
1. 先安装对应版本 Fabric Loader
2. 把 Fabric API 放入 mods 文件夹
3. 下载本模组的 jar 文件，同样放进 mods 目录
4. 启动 Fabric 版本游戏即可
